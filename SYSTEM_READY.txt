🔄 DATA FLOW (Employee Creates Log):

1. Employee fills form & clicks "Save"
   ↓
2. Frontend sends: POST /api/work-logs
   ├─ With JWT token in Authorization header
   ├─ With log data (title, accomplishments, date, etc)
   ↓
3. Backend receives API request
   ├─ Verifies JWT token is valid
   ├─ Extracts userId from token
   ├─ Validates all required fields
   ↓
4. Backend saves to MongoDB
   ├─ Document created in WorkLogs collection
   ├─ Timestamp added (createdAt)
   ├─ Returns new log ID
   ↓
5. Backend logs to ActivityLog collection
   ├─ Records: "user_id created log_id"
   ├─ Records: timestamp, IP, userAgent
   ↓
6. Backend sends response to Frontend
   ├─ HTTP 201 Created
   ├─ Success message
   ├─ New log data
   ↓
7. Frontend receives response
   ├─ Shows success notification
   ├─ Adds log to in-memory list
   ├─ Increments total count
   ├─ Updates status breakdown
   ├─ Refreshes graphs
   ↓
8. ✅ RESULT: Log visible everywhere
   ├─ Employee Dashboard (My Logs list)
   ├─ Employee Statistics (total count +1)
   ├─ Employee Graphs (status distribution updated)
   ├─ Admin "All Logs" view
   ├─ Admin Activity Log
   ├─ Admin Statistics (updated)
   ├─ MongoDB (persistent forever)
   └─ Even if backend restarts, data is there!
